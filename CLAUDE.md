# ImageLinkBot — инструкции для Claude

- Всегда отвечай только на русском языке.
- Бот Telegram: присылаешь картинку — получаешь публичную ссылку на неё. Картинка сохраняется в
  `../image` (рядом с папкой кода), ссылка — `${HOST}/image/<файл>.jpeg`, отдаёт её nginx;
  каждое сохранение пишется в коллекцию `SaveLog` базы `IMAGE`.
- В репозитории — **скомпилированный JS** (как работал на сервере с 2025-01): исходники на
  TypeScript не сохранились. Правки — прямо в `.js`.
- Где и как запущен на сервере — `README.md`.
